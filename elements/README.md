# Elements

Ce dossier contient des ressources de travail et d'archive qui ne sont pas importees par l'application Astro.

Contenu typique:
- `content/`: brouillons ou sources editoriales intermediaires
- `docs/`: documents de reference externes
- `mockups/`: maquettes, exports et references visuelles
- fichiers divers: images ou archives conservees pour contexte projet

Statut:
- non deploye
- hors du chemin critique de build
- a conserver comme archive projet tant qu'il reste utile

Si un element doit devenir source de verite applicative, le deplacer ou le recopier explicitement vers `src/data`, `src/assets` ou `public` selon son usage.
